# SchoolCanteen · Served ≠ Eaten — demo prototype

Live: https://sanadhamadd.github.io/schoolcanteen/ (QR: `schoolcanteen-qr.png`)

Frontend-only (Vite + React + TypeScript). All data is illustrative and lives in `src/data.ts`.

- Restart the demo on a phone: tap the yellow **SC** button → **Restart the demo**.
- Run locally: `npm install`, then `npm run dev`.
- Redeploy after edits: `npm run build`, then push the `dist/` folder to the `gh-pages` branch.
